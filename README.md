## 🌌 Sobre o Projeto

O **Gatonautas - Nave Gaton IX** é um projeto acadêmico desenvolvido para a disciplina de Programação Web.

O site apresenta um universo fictício onde gatos astronautas exploram planetas, realizam missões espaciais e interagem com usuários através de funcionalidades dinâmicas e interativas.

O projeto foi desenvolvido utilizando:

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- APIs externas

---

# 🪐 Funcionalidades

## ✨ Funcionalidades Gerais

- 🌙 Sistema de tema escuro
- 📱 Layout responsivo
- 🍔 Menu hambúrguer mobile
- ⬆️ Botão interativo de voltar ao topo
- 🎨 Interface espacial com animações
- 🌌 Background animado com estrelas e meteoros

## 🧑‍🚀 Página de Tripulação

- Consumo de API de imagens de gatos
- Geração dinâmica dos cards da tripulação
- Informações personalizadas para cada personagem
- Armazenamento local usando LocalStorage

---

## 🛰️ Página de Galeria

- Consumo da API pública da NASA
- Exibição dinâmica de planetas
- Informações fictícias sobre missões espaciais
- Cards gerados automaticamente via JavaScript

---

## 📨 Página de Voluntariado

- Formulário interativo de recrutamento
- Sistema de classificação espacial
- Feedback visual dinâmico
- Persistência de mensagens holográficas
- Armazenamento dos hologramas em LocalStorage
- Sistema de limpeza da sala holográfica

---

## 🛍️ Página de Produtos

- Catálogo fictício de produtos espaciais
- Cards estilizados
- Navegação integrada com outras páginas

# ⚙️ Como Executar o Projeto Localmente

## 1️⃣ Clone o repositório

```bash
git clone https://github.com/Serminho/gatonautas-web
````

---

## 2️⃣ Abra a pasta do projeto

```bash
cd gatonautas-web
```

---

## 3️⃣ Instale as dependências

```bash
npm install
```

---

## 4️⃣ Configure o arquivo `.env`

Crie um arquivo:

```env
CAT_API_KEY=SUA_CHAVE_DA_API
```

---

## 5️⃣ Execute o servidor

```bash
node server.js
```

---

## 6️⃣ Abra o projeto

Abra o arquivo:

```bash
index.html
```

ou utilize a extensão **Live Server** no VSCode.
